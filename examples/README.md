# Example result files

These JSON reports were generated by the documented pure-Python commands and are provided as **reproducibility examples**, not validated humanoid research results:

- `reports/closed-loop.json`: one-seed end-to-end toy imitation benchmark.
- `reports/suite.json`: eight-seed paired synthetic evaluation.
- `reports/diagnostics.json`: 100-trial algebraic hypothesis-identification benchmark.

They contain no raw robot data and no actual VLA model inference. See [RESULTS.md](../RESULTS.md) and [VALIDATION.md](../VALIDATION.md).
