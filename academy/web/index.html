CODE X-RAY · PREVIEW

Five lines worth understanding

# 1. Observe where the robot is
q = robot.joint_positions()
# 2. Compare the tip position with the cup
error = target - forward_kinematics(q)
# 3. Convert Cartesian error to joint motion
dq = damped_least_squares(q, target)
# 4. Send a small joint update
robot.command(q + dt * dq)
# 5. Measure again and repeat

UNDERSTAND & VERIFY

What makes it intelligent?

The robot uses an error signal and a Jacobian to decide how its joints should move towards the target. MuJoCo simulates the resulting dynamics; feedback corrects deviations.

q̇ = Jᵀ (J Jᵀ + λ² I)⁻¹ K (x* − x)

The damping term limits extreme commands near singularities. This is classical feedback control, not a learned AI policy yet.
